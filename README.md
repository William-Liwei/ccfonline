# CCF Online

会议截稿、CCF 推荐目录与期刊分区，一页查全。

**[打开 CCF Online →](https://www.weili.space/ccf/)**

## 能做什么

- **查会议截稿**：倒计时、多轮截稿、摘要截止时间与录用率，支持北京时间、本机时区和会议原时区。
- **查 CCF 推荐目录**：按领域、类型、级别和出版社筛选 2026 版目录，联查会议截稿与期刊分区。
- **查期刊分区**：JCR 2025、中科院分区 2025、新锐分区 2026 合并查询，可按期刊名或 ISSN 搜索。
- **收藏与分享**：收藏常用会议和期刊，一键复制带筛选条件的链接；收藏保存在自己的浏览器中。
- **随手使用**：无需注册，支持手机访问与深色模式。
